# B8A1 - Problem Solving with TypeScript and OOP

This repository contains my solutions for Module 4: Assignment 1 (Problem Solving with TypeScript & OOP) of Programming Hero Level 2 Web Development.

## Assignment Overview

All problem-solving tasks have been implemented in `solutions.ts`.

### Problems Solved:
1. multiplyValue: Handles optional multiplier with default value of 2 and properly multiplies by 0.
2. processInput: Uses typeof type narrowing to format strings, numbers, and booleans.
3. formatCoordinate: Accepts a readonly tuple [number, number, string] and returns formatted coordinate string.
4. concatenateArrays: Generic function accepting rest parameter arrays and returning a single merged array.
5. getPopularCourses: Filters published courses with minimum students criteria using the Course interface.
6. pluckValues: Generic function using keyof constraint to extract property values from an array of objects.
7. Employee and Manager: Demonstrates OOP principles with protected and private access modifiers and inheritance.
8. validateAgeAsync: Asynchronous function that resolves after 1 second or rejects with an Error object.
